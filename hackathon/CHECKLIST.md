其他東西都準備好了：產品、文案、影片腳本、X 貼文、公開 repo 的安全掃描。

## 1. 建立公開 GitHub repo（約 5 分鐘，11 月 3 日前）

- [ ] 到 GitHub 建一個新的 **Public** repo，名稱例如 `delomu`，**不要**勾選加入 README。
- [ ] 告訴 Claude「repo 網址是 …，幫我推上去」。Claude 會推送 `main` 分支（含完整 git 歷史，評審看得到每一步的日期）。
- 已確認不會公開的：`demo-data/`（金鑰、資料庫）、`outreach/`（客戶名單）、`.impeccable/review/`、影片檔和影片暫存檔（`hackathon/video/*.mp4`、`hackathon/video/build/`）。
- 已掃描整個 git 歷史：沒有任何真的金鑰。

## 2. 影片（已完成，你只要看一遍）

- [ ] 要交的是 Clueso 版：`hackathon/video/delomu-demo-clueso.mp4`（2:11，1080p，英文配音和字幕）。看一遍。
- 配音是 Clueso 的 AI 語音（ElevenLabs 的 Jeff），不是你本人的聲音；提交文案裡已經註明。
- 右下角有「Made with Clueso」浮水印（免費方案）。升級 Clueso 後告訴 Claude，它會重新輸出一支沒有浮水印的版本。
- 要改內容：直接在 Clueso 編輯器改 https://web.clueso.io/guide/7900a2a6-5175-4c6c-bcfc-fd09326f2ff6 ，再輸出。
- 備用版（沒有浮水印、自己產生的）：`hackathon/video/delomu-demo.mp4`（2:12）。

## 3. 上傳影片

- [ ] 上傳到 YouTube，設成「不公開（Unlisted）」。用無痕視窗確認能播、有聲音。
